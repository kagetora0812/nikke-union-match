UNION MATCH + BOT

UNION MATCHは、BOTを導入しなくてもご利用いただけます。

BOTを導入することで、募集情報や公式イベントの通知、ユニオン管理がより便利になります。

初回連携後は、DiscordからPASSの入力不要でサイトをご利用いただけます。

導入・利用無料。外部サービスの契約も不要です。

QUIET NOTICES

通知内容や通知先は自由に設定できます。

必要な通知だけを受け取れるため、普段のコミュニケーションを妨げにくい設計です。

BOT FEATURES

公式情報

レイド・協同作戦・イベント・新キャラクター情報を通知。

X指揮官募集

Xでユニオンを探している指揮官の投稿を自動収集・通知。

新着指揮官

UNION MATCHに登録された新着指揮官を通知。

ログインリマインダー

NIKKE公式Discordのログインリマインダーを毎朝7時にお届け。

掲載期限

掲載期限を事前にお知らせ。通知からそのまま延長。

ユニオン管理

PASS不要で、Discordから募集状態の切り替えや掲載管理ができます。

CHARACTERS

ツンデレ・執事系・妹系・自由設定の4種類から選択できます。

初期設定ではキャラクター名が設定されています。お好みの名前や写真に変更してご利用ください。

COMMANDS

コマンドをクリックするとコピーできます。

/setup

初期設定・通知設定

/botprofiles

キャラクター設定

/unionmatch

ユニオン管理

/guide

使い方ガイド

/channelcheck

通知チャンネルの権限確認

/

Discordのメッセージ入力欄に「/」を入力すると、利用できるコマンドが表示されます。

EASY TO START

BOTのご利用には、UNION MATCHへのユニオン登録が必要です。

メンバーを募集していないユニオンも「登録のみ」でご利用いただけます。

01

ユニオン登録・PASSを取得

02

BOTをDiscordサーバーに追加

03

/setup を実行し、初期設定・PASS連携

導入・初期設定にはDiscordサーバーの管理権限が必要です。

ユニオン登録は14日間有効。Discordから延長できます。
